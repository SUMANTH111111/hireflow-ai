# HireFlow AI – Intelligent Recruitment Platform

An AI-powered recruitment platform that helps enterprises post job openings and enables recruiters to identify the most suitable candidates using intelligent resume matching and application tracking.

## Features

### Enterprise

* Secure login
* Create and manage job openings
* Add required skills and job descriptions
* View posted jobs

### Recruiter

* Secure login
* Upload and manage candidate resumes
* AI-powered resume matching
* Candidate ranking with match scores
* Application status management

## Technology Stack

| Layer           | Technology            |
| --------------- | --------------------- |
| Frontend        | HTML, CSS, JavaScript |
| Backend         | Python (Flask)        |
| Database        | MySQL                 |
| AI              | OpenAI API            |
| Version Control | Git & GitHub          |

## Project Structure

* `app.py` – Main Flask application
* `database.sql` – Complete database schema
* `templates/` – HTML pages
* `static/` – CSS, JavaScript, images, uploads
* `models/` – Database connection layer
* `docs/` – Architecture and requirement documents

## Database Tables

* Users
* Jobs
* Candidates
* Applications

## Status Pipeline

Applied → Shortlisted → Interviewed → Selected / Rejected
